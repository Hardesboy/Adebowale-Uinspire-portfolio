# Osho Adebowale | Personal Portfolio

A responsive, professional portfolio website showcasing my dual expertise as a Doctor of Pharmacy candidate, Bioinformatics Researcher, and Brand Strategist. Built for the U-inspire Assignment.

## 🚀 Features

*   **Responsive Design:** Fully optimized for desktop, tablet, and mobile viewing.
*   **Modern UI/UX:** Clean styling, readable typography, and smooth scrolling.
*   **Project Showcase:** Highlights academic research (in silico phytochemical studies) alongside community initiatives and digital marketing projects.
*   **Custom Assets:** Structured repository utilizing dedicated icon and image asset directories.
